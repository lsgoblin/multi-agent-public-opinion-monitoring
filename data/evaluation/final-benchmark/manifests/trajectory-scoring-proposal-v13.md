# 走势评分口径建议 v13（供主 Agent 核定）

**状态：** 内部执行建议，不是命题硬门槛。命题要求在 10—20 件真实历史事件上回测升级/平息方向并报告一致率；正式最低数量、cutoff、窗口、来源覆盖和方向定义尚无主办方书面确认。该页请主 Agent 在 2026-10-09 10:00 批次冻结前确认或修订。

## 建议冻结的可执行口径

1. **事件身份：** 同一个底层争议只计一次。来源文章、转帖、作者、投诉 case 和多次运行都不是新事件。多个机构只有在共同构成同一明确集体争议时才能合并，并须先写清身份边界。按事件而非文本划分开发/留出。
2. **cutoff 与输入：** 固定一个可复核版本与时区明确的 `available_at`；输入仅含不晚于 cutoff 的冻结材料。来源 URL 仅作溯源。预测先封存输入、程序/配置哈希及输出，再开放未来证据与标签。
3. **窗口建议：** 使用完整 UTC 日，排除 cutoff 所在 D0；基线 D−7…D−1，观察 D+1…D+7。窗口长度是内部建议，不是命题要求。若主 Agent 选择 7×24 小时或其他窗口，必须一次性冻结，后续事件不变口径。
4. **来源覆盖：** 每个来源固定查询词、语言/地域、平台/版面范围、分页、去重方式和抓取时间。建议至少一个公众讨论来源及一个独立来源族；新闻报道/搜索量只称传播代理，不当作公众情绪真值。每窗建议至少 6/7 个可核日且至少 5 个事件相关单位；接口封顶、归档覆盖不明、混杂查询或来源不一致时记 unknown。
5. **方向：** 两来源日均讨论量都至少为 1.5 倍才建议 `escalation`，都至多为 0.67 倍且有连续下降证据才建议 `calming`；落在中间且无反向证据才建议 `stable`。业务恢复、诉讼结果、单次回应或没有搜到内容都不等于平息。
6. **零基线：** 比值未定义。建议默认 `unknown`；可选方案是单独冻结“从零基线上升”条款，例如两个来源均出现至少 5 个相关单位，分布在至少 3 个观察日，且不存在强反证，方允许人类标 `escalation`。本条需主 Agent 明确选择，不能由 C 为扩样自行应用。
7. **真人标签：** 两位独立真人盲态标注同一冻结证据包，分别提交方向和理由；保留原答，分歧交独立裁决。稳定/unknown 单独统计，不转写成升级/平息。预测只能在结果标签提交后暴露。
