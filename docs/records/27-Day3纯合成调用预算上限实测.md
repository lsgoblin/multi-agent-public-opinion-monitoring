# Day 3 纯合成调用预算上限实测

> 2026-10-05。用户授权一次 ¥2.36 上限测试。本记录只回答当时纯合成提示词与计费保护规则下可发送的实际调用次数；不是 500 Agent × 30 轮仿真，**G3 未通过**。机器可读结果见[运行 JSON](../../data/research/day3_synthetic_budget_cap_20261005.json)；Day 3 DeepSeek 探针代码已从当前工程移除。

## 范围与停止规则

- 模型固定 `deepseek-flash`、非思考模式、JSON 动作输出；输入为虚构保险服务事件、匿名角色参数和局部状态、运行时生成的模拟消息、该角色自身模拟记忆。没有发送 UnitedHealth、SEC、Optum、黑猫或其他真实来源，也没有发送凭据、真实账号和个人信息。
- 每次请求最多 160 输出 tokens；发送前检查合成提示词 UTF-8 字节上限 6,000，并预留 ¥0.02。并发上限 10；不重试无效结果。请求、失败和用量均累计到同一次 ¥2.36 测试。
- [DeepSeek 官方人民币价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)规定闲时百万 tokens 的缓存未命中输入 ¥1、命中输入 ¥0.02、输出 ¥4，法定节假日全天按闲时价。[国务院 2026 年放假安排](https://big5.www.gov.cn/gate/big5/www.gov.cn/zhengce/zhengceku/202511/content_7047091.htm)将 10 月 5 日列入国庆假期。预算闸门对上述三项价格各加 10% 缓冲，按每个响应的缓存命中/未命中和输出 token 核销；缺用量的响应按 ¥0.02 预留额计入。另保留更高的高峰价估算用于审计，不将它冒充实际扣费。
- 保护账本剩余不足 ¥0.02 时停止新请求；账号余额 API 仅作旁证，不能代替逐请求闸门。其余额精度为分，分段之间可能有结算延迟或同账号活动。

## 结果

| 项目 | 实测 |
| --- | ---: |
| 已发送请求 | **4,140** |
| 有效结构化决策 | **4,137** |
| 无效决策 | 3（首段 1 次响应未保留 usage，后续 2 次 usage 已计入） |
| 有回执的输入 / 输出 tokens | 1,553,281 / 257,222 |
| 有回执的合计 tokens | **1,810,503**；另 1 次无效响应缺 usage，不能记零 |
| 输入缓存命中 / 未命中 tokens | 482,688 / 1,070,593 |
| 动作分布 | `observe` 3,919；`share` 182；`seek_clarification` 36 |
| 生成的模拟消息 | 182 |
| 假日价加 10% 缓冲的保护账本 | **¥2.340048236** |
| 距 ¥2.36 上限的保护余额 | **¥0.019951764**，不足下一请求 ¥0.02 预留 |
| 独立高峰价保守估算 | ¥5.081923424；不是本次假日费用或账单 |

容量测试分为 4 个连续计量片段。最初 100 次中的一条模型响应不符合决策契约，探针按原规则停止；保留失败与 ¥0.02 保守计费后继续同一授权内的测试。后续一次无效响应同样未重试。分段恢复重置了模拟 Agent 状态，末尾又采用小批次以用完可预留额度，因此 4,140 次是**调用容量观察值**，不是一条连续的 500 × 30 动态轨迹，也不能证明真实模型的消息因果。

该数值是本次提示词、动作分布、缓存命中、假日价格和安全预留的结果，**不是“¥2.36 永远最多只能调用 4,140 次”**。在这批请求的保护账本均价下线性外推，15,000 次约需 ¥8.48，超过当时的 ¥2.36 上限，也超过后来提高的 ¥5.00 上限；后续轮次的上下文长度、缓存和动作分布变化会改变费用。账号余额 API 的各片段可见差额合计约 ¥1.90，但没有同一时刻的高精度账单，也不能排除片段间结算或其他活动，故不记为实际账单费用。用户提高后续单次完整任务上限不追溯扩大本次测试授权；没有新增调用、提交、推送、部署或进入 Day 4。
