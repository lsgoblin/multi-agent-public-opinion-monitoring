# Day 3 百炼混合模型 50 Agent × 5 轮分级试验

> 2026-10-06。用户已授权 10×3、50×5、100×10 三档纯合成分级实验；本记录只说明第二档。脱敏[运行 JSON](../../data/research/day3_synthetic_bailian_50x5_20261006.json)与本地 SQLite 保留供审计。**50×5 有 10 次失败，不是无失败完成；G3 未通过。**

## 执行边界

- 50 个 Agent 中 20 个固定路由 `qwen-turbo`、30 个固定路由 `qwen-flash`；5 轮共 250 次决策机会。显式 `max_calls=250`、并发数 4、预算 ¥5.00，没有自动重试。连接复用和安全传输分类已在本次运行前完成离线回归；此前[10×3 传输失败](34-Day3百炼混合10x3分级试验.md)的具体子类仍未知。
- 外发仅限纯合成虚构事件、匿名人设与局部状态、运行时实际消息、该 Agent 自身记忆及允许引用 ID；没有真实 SEC、Optum、黑猫材料、账号、个人信息、其他 Agent 私有记忆或密钥。历史 cutoff 不因本试验改变。
- 两模型同用预算闸门。按 8,192 输入与 160 输出 tokens 的当时配置、阿里云官方[`qwen-turbo`](https://help.aliyun.com/zh/model-studio/qwen-turbo)和[`qwen-flash`](https://help.aliyun.com/zh/model-studio/qwen-flash)北京标价，250 次机会保守预留 **¥0.47568**，低于本档 ¥5.00。价格标签仅记录本地核对日期，不锁定供应商版本。

## 真实运行结果

| 项目 | 结果 |
| --- | --- |
| 请求与轮次 | 250/250 次请求机会已尝试、5/5 轮执行完毕；`run_status=complete` |
| 决策 | **240/250** 有效、**10/250** 失败，`completed_without_failures=false`；失败均在第 4、5 轮的 `qwen-flash`，其中 `finish_reason` 类 4 次、`response_contract` 类 6 次，日志不能进一步确认原始响应内容 |
| 分模型 | `qwen-turbo` 100/100 有效；`qwen-flash` 140/150 有效。成功请求的 usage 合计输入 **82,303**、输出 **22,232**、缓存输入 **0** tokens；`unknown_usage_calls=10` |
| 本地费用 | **¥0.05821845**，包含 10 次失败的 **¥0.014688** 保守预留；并非已确认的供应商账单 |
| 动作与传播 | `observe` 189、`share` 36、`comment` 15；共持久化 153 条运行时消息 |
| 跨轮输入 | 有效决策中 63 次收到前轮消息，5 次动作引用了消息 ID；190 次包含自身记忆。消息进入观测与被引用已有真实证据，但未做移除消息的对照推演，不能据此断言动作因消息而改变 |

按轮看，第 1—3 轮均为 50/50 有效；第 4 轮 44/50，第 5 轮 46/50。`qwen-flash` 成功输出在后期最高达到 154 tokens，接近当时 160 的输出上界；这提示上界可能是失败因素之一，但不能从脱敏历史日志断定 10 次失败均为截断。第 5 轮结束后本档授权已用完。

依[Day 3 工程决策](../planning/24-Day3工程决策.md)，100×10 已获用户授权但暂缓，先做离线输出上界和响应分类修复、重新核算 ¥30.00 全任务保守预留，再决定是否放行。测试替身、含失败的 `complete` 或预算触顶的 `partial` 均不算 G3 通过。500×30 真实运行与严格消息因果仍缺失；**G3 维持未通过**。

后续完成该离线修复并执行了已授权的 100×10，结果仍含决策 schema 失败，见[36 号记录](36-Day3百炼混合100x10分级试验.md)。本记录的 50×5 数值保持历史原样。
