## 范围和来源

以[Day 1 时间证据事件](../../data/public/unh_change_20240222_event_v2.json)为同一事件种子。SEC EDGAR 适配器只接受该记录的 `sec.gov/Archives/edgar/data/` 原件 URL；帖子存档适配器只取公开帖标题、目标链接、归档抓取时刻，并校验其指向同一 SEC accession。当前接口不开放任意 URL 抓取，不保存帖子账号、评论或完整 SEC HTML。SEC 公开申报的[访问与复用说明](https://www.sec.gov/about/webmaster-frequently-asked-questions)允许研究使用；存档元数据仅供内部时间证据核验，不输入收费模型或公开再分发。黑猫原投诉仍保持历史可见时间未知。

使用[助手生成的标签建议](../../data/research/unh_change_20240222_day2_label.json)试验三分类标签录入接口，建议为 `neutral`，接口返回 `submitted_label_identity_unverified_not_formal_truth`。该建议仅供人工判断时参考；它不是人工标签、独立复核真值、网络事件风险或舆情方向判断，不计算准确率。接口不验证提交者身份，G2 人工初标仍缺。

接口路径为 `POST /cases/{case_id}/observations/collect`、`GET /cases/{case_id}/observations`、`POST/GET /cases/{case_id}/labels`、`POST /cases/{case_id}/graph`、`GET /graphs/{graph_id}` 和 `POST /graphs/{graph_id}/query`。采集请求传入 `record_id` 与 `adapter=sec_filing`；存档请求另传 `adapter=arctic_shift_post` 和 `post_id=1axi1g0`。构图前需先导入已审计的事件包。

构图 HTTP 200，图 ID `64062b56694c343cb4f9c496`，只有截止前原始记录的 1 条主张。查询 `Change Healthcare systems` 返回原始 SEC URL、记录 ID、可见时间和两条实际采集观察 ID，并沿“事件→主张→来源→发布者”关系返回子图。后续 8-K/A 的资金支持信息未出现在图或查询结果。图 ID 与观察内容相关，来源变化会产生新版本。原件内容摘要来自已审计事件包；同期存档只证明原件链接和标题当时可见，没有保存当刻完整 HTML 字节。
