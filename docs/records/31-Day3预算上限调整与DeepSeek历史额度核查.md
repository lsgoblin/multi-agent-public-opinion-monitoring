## 决定与测算边界

代码工程师给出的 500 Agent × 30 轮保守预留为 **¥28.5408**。这对应每轮 200 个 `qwen-turbo`、300 个 `qwen-flash`，每请求按 8,192 输入与 160 输出 token 上界预留，共 15,000 次决策机会；以每百万 token 的假设单价 `qwen-turbo` 输入 ¥0.3／输出 ¥0.6、`qwen-flash` 输入 ¥0.15／输出 ¥1.5 计算，不计缓存折扣：

```text
200 × 30 × (8,192 × 0.3 + 160 × 0.6) / 1,000,000 = ¥15.3216
300 × 30 × (8,192 × 0.15 + 160 × 1.5) / 1,000,000 = ¥13.2192
合计 ¥28.5408；¥30.00 - ¥28.5408 = ¥1.4592
```

上述价格是本次预算测算的**输入假设**，不是本记录核实的当日供应商报价。尤其 `qwen-flash` 的实际北京价格、版本和三类 token 单价仍须在首次请求前核对并填写本机 `.env`。费用闸门继续按配置价格、逐请求最大输入/输出和并发预留计算；缺 usage 时保留保守预留。¥1.4592 是失败、缺 usage 及其他任务模型费用的预留空间，不保证足以完成所有后续阶段。若触顶则停止并标 `partial`，不得报告 500×30 完成。
