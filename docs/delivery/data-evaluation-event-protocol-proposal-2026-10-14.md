# 事件走势评测协议修订提案（2026-10-14）

> 状态：`data-evaluation` 提案，待总 Agent 协调确认；不追认旧运行，也不改变[新版命题](../sources/2026-09-30-新版命题-多智能体仿真舆情监测.md)的 ≥70% 方向一致率和本任务要求的 20 件可评分独立真实事件。当前没有正式非零分母。

## 发现的问题

旧公司名宽泛命中数没有事件归属，有时连查询覆盖也不能证明；只用严格标题词组又会漏掉相关帖子。一个开发诊断中，State Farm 2023 年加州新保单事件的基线原始检索为 10 帖，固定标题规则留下 7 帖；观察窗原始检索为 3 帖，规则留下 0 帖。但两个窗口的被排除标题里分别出现了直接谈及停止加州新业务以及监管回应的帖子。因此“规则匹配为零”不能写成“事件讨论为零”，这件诊断样本不能给模型记对错。原始规则和产物保留，不能看结果后改词重算。详情见主工作区 `artifacts/branch-work/data-evaluation/evidence/20261014/fresh-attribution-audit-state-farm-v1.json`。

## 建议冻结的顺序

1. **独立选事件。** 先登记具名公开披露来源及日期、具体动作、主体、与开发事件的关系、来源使用范围和版本；同一事件的后续报道不得拆成多件抬高分母。留出事件须在调方法和阈值之前固定。以 20 件最终可评分为目标，先准备更大的候选池，逐件公布排除原因。
2. **固定检索与时间边界。** 每件事在接触观察窗或预测结果前，定下高召回检索式、实体别名、标题/URL 判读说明、cutoff、等长基线和观察窗、时区。当前“披露日后第七天 00:00 UTC、前后各七个完整 UTC 日且跳过 cutoff 日”只是试行方案。保存所有原始命中 ID、标题、URL、发布时间、查询参数、返回版本和覆盖标记。近似命中、分页截断或失败窗口不能记零；[采集约束](data-evaluation-event-collection.md)给出可穷尽检查。
3. **先审基线归属，再预测。** 对原始命中逐条记录 `include` / `exclude` / `cannot_judge` 与原因；不能只保存规则选中的帖子。正式归属需要两个互不见答案、看不到预测的真人独立判断，分歧保留并记录裁决；暂缺真人时 AI 复核仅用于辅助。若明显相关的原始命中被事前规则漏掉，或检索无法覆盖事件讨论，修订规则只能用于**后续全新留出事件**，当前事件退出该方法的留出集。入选故事 ID 和所属评论构成截止前输入包，哈希冻结。
4. **冻结真实预测。** 真正用于方向指标的行必须是完整真实历史输入的动态多智能体运行导出，含明确的事件 ID↔主记录 ID、cutoff、来源版本、方法版本、独立状态/记忆和消息作用证据、完整轮次、模型调用与 token/费用账本；通过 `evaluation_prediction_import` 的 `live_multi_agent_simulation_v1` 准入后才能参与配对。单模型 qwen-flash、常量基线、`partial` 和 AI 标签只进独立辅助账本。预测输入不得含未来观察或标签，预测文档与冻结记录须在读取观察窗前落盘并核哈希。
5. **再审观察归属。** 按同一高召回检索式抓观察窗新故事和截止前已入选故事的观察窗评论，逐项证明覆盖；观察新故事仍需独立盲审归属。不能把检索式未命中的未知讨论或未通过归属的帖子当作零。故事 ID、评论 ID 全局去重；只汇总事前定义的来源家族，不写成公司全渠道投诉量。
6. **形成独立真值。** 真人标注员在看不到预测和彼此答案的条件下，用已核归属的观察证据分别给 `escalation`、`calming`、`stable` 或 `cannot_judge`；两人一致或有具名裁决才有正式真值。当前备选机械敏感性规则 `B≥20`、同口径 `O/B` 超出 ±10% 才给升/降，仍未批准，也不代替人工判断。`stable` 和 `cannot_judge` 单列覆盖及排除，不能强塞进二分类。规则选择必须在全新留出事件的观察结果和预测揭盲之前完成。
7. **逐单位评分。** 只有事件身份、来源许可、截止前可见性、完整预测、可比观察、独立真人标签同时成立的单位进正式分母。报告列每件证据版本/哈希、预测与真值、排除原因、方向正确数/分母、情感混淆矩阵、负面 precision/accuracy/recall、覆盖和真实调用账本。20 件可评分、方向 ≥70% 以及其他目标均须由实测证明；候选数、AI 一致率、工程测试通过数不算验收。

## 需要协调的接口

`simulation-scale` 的现有方向导出尚不能直接形成 `prediction_import.v1` 所需的完整历史运行包。请总 Agent 协调增加真实 `backend_mode`、运行配置摘要、可解析 ledger 引用及 `event_id`↔`record_id` 对应；`data-evaluation` 只在本分支实现导入和评分，不改共享 API、schema、网关或仿真分支文件。正式规则与人工盲标排期须由总 Agent 统一确认。

## 本提案的适用边界

本次 State Farm 诊断和已用于开发的旧 10 件不能再为此修订协议充当未参与规则制定的留出证据。Hacker News 当前历史索引可提供条目创建时间，但不是历史时点的完整索引快照；正式结论还须核其来源使用范围、历史可见性和跨来源代表性。[新版命题](../sources/2026-09-30-新版命题-多智能体仿真舆情监测.md)的五平台覆盖另行验收，不能由单一 HN 事件序列代替。
