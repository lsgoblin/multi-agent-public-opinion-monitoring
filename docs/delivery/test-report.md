### 指标解释约束

- “有效决策”是运行账本接受的 Agent 决策数；不能将请求机会数、轮次完成或消息数量等同于全流程质量达标。
- 预警比例分母是最后一轮有效决策数，分子是模拟 `express_complaint_intent` 数；它不是现实投诉量。
- 历史材料的 `real_historical` 标记只描述来源性质。`offline_dynamic_substitute` 表示本机替身决策，未调用真实模型。
- `synthetic` 可用于隔离测试或纯合成功能演示；不得与真实事件证据拼接成真实回测。
- `dry_run` 只证明预览载荷生成。应用账本 `network_requests=0` 不是操作系统抓包/容器出站审计。
- cutoff 外、可见时间未知或 `evaluation_only` 的历史材料不得进入图检索、Agent 记忆或推演。历史结果不能反向变成当时已知信息。
