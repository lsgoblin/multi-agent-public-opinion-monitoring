使用现有虚拟环境、临时 SQLite 和真实 HTTP 请求：事件导入 HTTP 200；SEC 原件采集 HTTP 200；[同期帖子存档](https://arctic-shift.photon-reddit.com/api/posts/ids?ids=1axi1g0)采集 HTTP 200，保留字段的 SHA-256 为 `c6cd9db840ae0702fbbd8f2a25f9f9b16c520813da36bcae1d1cb4d18738b84b`，抓取时刻为 `2024-02-22T21:18:39Z`。存档见证先于[既定 cutoff](../../data/research/unh_change_20240222_visibility.json)。SEC 页面响应会插入每次请求不同的脚本和像素标签，因此去重哈希现按去除这些标签后的原件标记内容计算；原始响应不持久化。

使用[助手生成的标签建议](../../data/research/unh_change_20240222_day2_label.json)试验三分类标签录入接口，建议为 `neutral`，接口返回 `submitted_label_identity_unverified_not_formal_truth`。该建议不是人工标签。用户 Leo 随后提交了[书面初标](15-Day2人工情感初标表.md)，标签同为 `neutral`，理由和提交来源分别记录；不把助手建议作为第二人复核，也不声称用户未受建议影响。此单条初标不构成正式准确率样本。

接口路径为 `POST /cases/{case_id}/observations/collect`、`GET /cases/{case_id}/observations`、`POST/GET /cases/{case_id}/labels`、`POST /cases/{case_id}/graph`、`GET /graphs/{graph_id}` 和 `POST /graphs/{graph_id}/query`。采集请求传入 `record_id` 与 `adapter=sec_filing`；存档请求另传 `adapter=arctic_shift_post` 和 `post_id=1axi1g0`。构图前需先导入已审计的事件包。
