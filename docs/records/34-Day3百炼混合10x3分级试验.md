# Day 3 百炼混合模型 10 Agent × 3 轮分级试验

> 2026-10-06。用户授权 10×3、50×5、100×10 三档纯合成分级实验；本记录只说明第一档。`qwen-turbo`／`qwen-flash` 共用单次任务预算闸门。脱敏[运行 JSON](../../data/research/day3_synthetic_bailian_10x3_20261006.json)与本地 SQLite 保留供审计。**10×3 含 1 次失败，不是无失败完成；G3 未通过。**

## 执行边界

- 北京地域两模型固定路由：10 个 Agent 中 4 个网民／客户角色使用 `qwen-turbo`，6 个媒体／KOL／模拟监管角色使用 `qwen-flash`。3 轮共 30 次决策机会；显式 `max_calls=30`、并发数 8、任务预算 ¥5.00，没有重试或额外调用。
- 外发仅限虚构事件、匿名人设与局部状态、实际产生的模拟消息、该 Agent 自身记忆、轮次和允许引用 ID。没有外发真实 SEC、Optum、黑猫材料、账号、个人信息或其他 Agent 私有记忆。
- 只读预检确认专用密钥、北京端点和两模型价格配置。每请求按 8,192 输入与 160 输出 tokens 保守预留；12 个 `qwen-turbo` 与 18 个 `qwen-flash` 请求的总保守预留为 **¥0.0570816**，低于 ¥5.00。价格标签仍是本地核对日期，不锁定供应商价格版本；标价依据为阿里云官方[`qwen-turbo`](https://help.aliyun.com/zh/model-studio/qwen-turbo)和[`qwen-flash`](https://help.aliyun.com/zh/model-studio/qwen-flash)北京页面。

## 真实模型运行结果

| 项目 | 结果 |
| --- | --- |
| 请求与轮次 | 30/30 次请求机会已尝试，3/3 轮执行完毕；`run_status=complete` |
| 有效与失败 | **29/30** 有效决策，**1/30** 失败；`completed_without_failures=false`。第 2 轮 `agent_0007` 的 `qwen-flash` 请求记录为 `BailianRequestError:transport`；没有供应商响应正文可用于进一步判定传输子类 |
| usage | 成功请求合计输入 **8,204**、输出 **2,487**、缓存输入 **0** tokens；失败请求 `unknown_usage_calls=1` |
| 本地费用 | **¥0.00615285**，包含失败请求的 **¥0.0014688** 保守预留。这是任务账本估算，不是已确认的供应商账单 |
| 实际动作 | `observe` 25、`share` 3、`comment` 1；没有失败动作被替换为有效动作 |
| 传播与记忆 | 第 2 轮产生 3 条消息，第 3 轮产生 9 条，共 12 条；第 3 轮有 3 个 Agent 的输入包含上轮消息，且 10 个 Agent 的输入包含自身记忆 |

第 3 轮收到消息的 3 个 Agent 分别作出 `observe`、`comment`、`share`，但有效动作引用均未包含收到的消息 ID。现有日志证明实际消息进入后续观测与独立记忆恢复，尚不证明消息使动作改变；[30 号记录](30-Day3跨轮上界与百炼验证准备.md)定义的处理／对照因果判据未通过真实模型对照验证。`run_status=complete` 只表示轮次结束，不表示 30/30 有效决策。

由于第一档出现传输失败，50×5 与 100×10 的既有授权暂缓执行，先做不外发的稳定性复核与保守并发调整，再决定是否升级；不把本次 `complete` 当作 G3 通过。500×30 真实运行、严格消息因果和完整预算证据仍缺失。历史 cutoff 继续采用“首次有证据证明输入可见的时间 + 30 分钟”，本次纯合成试验不改变该规则。
