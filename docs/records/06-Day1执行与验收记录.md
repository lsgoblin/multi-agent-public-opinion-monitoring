## 3. 实现与验证证据

- 使用已安装的 Python 3.12.4；通过 uv 在项目 `.venv` 安装依赖，生成 `uv.lock`，未修改系统 Python 环境。
- `uv run pytest -q`：17 项通过。覆盖幂等与版本冲突、持久化、未来记录/评测资料隔离、未知时间、无时区/重复 ID/混合数据拒绝、缺失投诉与零投诉区别、模型缺配置/截断/错误引用/错误响应处理，以及 Streamlit 导入和标签切换。
- 测试有 1 条上游 Starlette 对 httpx 测试适配器的弃用提示，不影响本轮通过；未来升级测试依赖时处理。本轮未为消除提示额外引入替代库。
- 公开案例 CLI 导入成功，保存 3 条记录；截止前输入接口仅返回 2024-03-14 一条，其他两条在评测侧读取。
- 本地 API `GET /health` 返回 `status=ok, stage=day1`；Streamlit `/_stcore/health` 返回 `ok`。进程只监听 `127.0.0.1`。
- `model-status` 返回 `not_configured`。`probe-model` 返回 `blocked`，进程退出码为 2，未向模型服务发送请求。单元测试中的响应替身不算真实模型证据。
- 内置浏览器连接失败，未取得浏览器截图；使用 Streamlit AppTest 检验页面脚本、案例导入、重复导入及“评测资料”开关，属于应用级功能验证，不冒充视觉验收。
