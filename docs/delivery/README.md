## 当前结论

- 生产模块按功能命名：`evidence`、`sentiment`、`source_probe`、`simulation`、`reporting`、`alerts`、`tasks`、`evaluation`。
- 本机真实历史材料演示执行 `offline_dynamic_substitute`，来源图为 `offline_archived_record_projection`；这不等于真实模型推演或在线 GraphRAG。
- 企微与邮件仅生成 `dry_run` 预览，不发送通知。Docker 已有本机构建、运行、重启持久化证据；完整容器出口隔离仍待实测。
- 真实历史事件已有**可计算的实测指标**：事件级（命题口径）情感 10 件三分类 70.00%、负面召回 100%、负面精确 66.67%；方向 10 件二分类 50.00%。四项目标中仅负面召回达标，事件数达到命题下限 10 件。记录级 94 条另有 84.04% 等数字，但**不得**当作事件成绩。详见[测试报告](test-report.md)与[评测证据](event-eval-20261014/README.md)。
- 走势结果来自 `formal_model_run_v1` 的真实模型方向预测，**不是动态多智能体仿真成绩**；仿真正式准入仍未打通，且"单事件 ≥500 Agent × 30 轮"这一项在真实历史事件上尚未验证。

其余运行账本与大体积原始产物保留在本机归档中，不属于精简后的源码提交。
