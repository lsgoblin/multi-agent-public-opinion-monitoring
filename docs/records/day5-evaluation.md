# Day 5 离线回测与指标计算

> 2026-10-08。本记录覆盖用户单独授权的 Day 5 本机离线评测工具与获授权本机数据试算。依据[新版命题](../sources/2026-09-30-新版命题-多智能体仿真舆情监测.md)及[赛题指标映射表](../design/05-赛题指标映射表.md)。这是一次受限试算，不表示 G3、G4 或 G5 通过。

## 工具与数据隔离

- [评测实现](../../src/riskshield/evaluation.py)只读取版本化输入 JSON 与独立标签 JSON，验证来源、可见时间、cutoff、预测和标签证据引用，再写入独立评测报告。标签不会导入 Store、知识图谱、检索、Agent 记忆或推演；文件引用作为本地 JSON Pointer 校验，不会复制来源正文进推演。
- [输入数据](../../data/evaluation/day5/inputs-v1.json)只记录输入快照、预测、执行模式和结果引用；[标签数据](../../data/evaluation/day5/future-labels-v1.json)单独存储人工情感标注与未来走势结论。未知或不确定的未来走势保持 `null`，不推造真值。
- [模板与字段说明](../../data/evaluation/day5/README.md)列明输入结构、合格条件与仓库根目录运行命令。输入和标签各有空 JSON 模板。
- 只有 `real_historical` 数据进入正式计算分母。测试中的合成记录只检验算式、缺失值处理和隔离逻辑；离线报告不把合成数据计入正式指标。
- 方向一致率按去重后的 `event_id` 计数；同一事件多个来源记录不能扩大事件分母。重复方向预测暂整体排除，待先指定唯一冻结预测行。

## 计算口径

| 指标 | 当前计算式 | 处理边界 |
| --- | --- | --- |
| 情感三分类准确率 | 三类预测正确的合格来源记录数 / 合格来源记录总数 | 真值要求至少两位不同标注者独立标注、均未见目标预测且一致；分歧不自动多数表决。输出真实标签为行、预测标签为列的混淆矩阵。 |
| 负面 precision 候选 | TP / (TP + FP) | 新版命题“负面识别准确率”正式定义待 V2-Q03 确认。 |
| 负面二分类 accuracy 候选 | (TP + TN) / (TP + FP + FN + TN) | 与 precision 同时报告，不替赛题选择主口径。将正面和中性合为非负面。 |
| 负面召回率 | TP / (TP + FN) | 无真实负面标签时分母为零，记不可计算，不记为 0%。 |
| 升级/平息方向一致率 | 方向相同的唯一真实事件数 / 有合格预测与结果标签的唯一真实事件数 | 只计显式 `escalation`/`calming`。稳定、弃权及窗口处理仍待 V2-Q05；每事件要求唯一预测。 |
| 历史事件样本量 | 合格且去重后的 `event_id` 数 | 命题写 10—20 件，精确门槛尚未确认；这里不降低或替换该要求。 |

缺标签、缺预测、非独立标签、来源引用失效、可见时间未知或晚于 cutoff 时，样本会带原因排除；分母为零时输出 `null` 和原因。报告同时保留 numerator、denominator、混淆矩阵、样本数、排除项和原输入/标签 SHA-256。

## 本机数据试算

从仓库根目录运行：

```powershell
uv run python -m riskshield.day5_evaluation --inputs data/evaluation/day5/inputs-v1.json --future-labels data/evaluation/day5/future-labels-v1.json --out artifacts/day5-evaluation/local-run-v1.json
```

复算结果见[机器可读报告](../../artifacts/day5-evaluation/local-run-v1.json)。输入版本为 `day5-authorized-local-data-v1`，标签版本为 `day5-authorized-local-labels-v1`。来源记录版本分别为 SEC 的 `unh-v2-2026-10-02-archived-visibility` 和 Optum 的 `unh-day2-multisource-2026-10-04-v1`。SEC 可见时间证据指向[独立公开引用记录](../../data/research/unh_change_20240222_visibility.json)中的 `2024-02-22T16:18:39-05:00`；cutoff 为其后 30 分钟的 `2024-02-22T16:48:39-05:00`。Optum 时间引用指向[Day 2 多来源包](../../data/public/unh_change_20240222_day2_multisource_event.json)的归档抓取 Unix 时间。其后 SEC 部分恢复记录只在标签文件作为评测候选证据引用。

| 项目 | 试算结果 |
| --- | --- |
| 输入行 / 不同来源记录 / 去重真实事件 / cutoff 合格事件 | 2 / 2 / 1 / 1 |
| 情感可计分记录 | 1 |
| 三分类准确率 | 0 / 1 = 0%；实际标签 neutral、预测 negative |

| 排除记录 | Optum 有一条人工初标，但标注者看过同事件其他结果，且此来源没有情感预测；因此不作为独立真值或计分预测 |

SEC 情感记录由 Leo 与 Li 两份已有独立人工标签支持，二者均为 neutral；DeepSeek 历史探测结果为 negative。它是对历史文本分类输出的回顾性评分，不是事前预测证据。唯一真实事件来自两个来源，事件样本量仍为 **1**。Optum 的后续资料描述部分恢复计划，没有正式标注其在指定观察窗内属于“升级”或“平息”；Day 4 离线替身报告也没有标准化二元走势预测，所以未计算方向一致率。没有进行模型调用、在线采集或通知。

## 阈值与关口

保留当前命题/映射表要求：三分类准确率 ≥88%；负面识别准确率 ≥90%（正式公式待定）；负面召回率 ≥85%；方向一致率 ≥70%；历史真实事件数 10—20（精确数待定）。当前一条可计分情感记录和一个独立真实事件都不足以验证这些总体要求。本记录仅提供可复算工具及一个历史分类样本的试算，不宣称正式达标或 G3/G4/G5 通过。
