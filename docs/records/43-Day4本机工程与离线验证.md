| --- | --- | --- |
| 五模块报告 | [报告模块](../../src/riskshield/reporting.py)从同一 `run_id` 的案例、截止快照、证据图、逐轮动作和消息生成传播、情绪、关键节点、风险及建议五部分；报告持久化并可按 ID 读取 | 传播边明确为模拟消息；情绪曲线由冻结的 Day 3 状态规则重建并逐 Agent 核对最终状态，属于派生的模拟状态而非真实舆情或原始逐轮快照；若核对不成立，则回退到明确标注的动作分布代理；建议列出来源/动作/消息 ID；缺少风险评估时标为未评估 |

| 本机任务执行 | [任务执行器](../../src/riskshield/tasks.py)持久化任务状态，后台运行现有动态仿真引擎；Agent 的动作根据当轮局部状态、实际运行时消息和自身记忆生成，完成后自动判级并生成报告 | 仅接受纯合成运行，模式固定为 `offline_dynamic_substitute`；`model_calls=0`、`network_requests=0`。它是测试替身工程证据，不是云模型、真实事件或 G3 证据 |
| API 与 Web | [API](../../src/riskshield/api.py)新增合成演示准备、任务启动/列表/状态、报告、预警及预览接口；[Web](../../ui/app.py)支持一键准备演示、启动执行、手动刷新逐轮进度与失败，并自动衔接报告和预警 | 手工创建仍只保存配置；明确点击“启动本机离线任务”才运行动态替身。500×30 历史合成账本与 Day 2 真实事件库分离，不拼成同一事件端到端报告 |
| Docker | [Dockerfile](../../Dockerfile) 与 [compose.yaml](../../compose.yaml)定义本机 API、Web 和持久化卷；主机端口仅绑定 `127.0.0.1` | Compose 配置校验通过；Docker 守护进程不可用，镜像构建、容器启动和域内无外发尚未实测 |

## 数据与关口边界

报告必须绑定 `case_id`、`graph_id`、`run_id`、`cutoff`、来源版本和 `data_mode`，并拒绝未知、未来或跨案例证据。Day 2 的真实历史事件图谱与 Day 3 的纯合成 500×30 运行属于不同案例；两者不能合并为一份真实事件推演报告。[500×30 运行](41-Day3百炼500x30真实规模尝试.md)已取得真实模型规模证据，30 轮全部结束，14,994 次有效决策和 6 次无效决策；严格消息动作因果仍待受控验证，**G3 尚未通过**。

Day 4 代码允许在本机对既有账本生成离线报告和预警，但不能据此宣称真实来源 GraphRAG、红警推送时效、通知送达、Docker 运行或 G4 正式达标。**G4 待实际运行证据复核，Day 5 未获授权。**
