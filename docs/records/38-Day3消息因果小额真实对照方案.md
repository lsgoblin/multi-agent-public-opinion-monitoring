> 2026-10-06。本文是首次尝试前的纯合成北京百炼 `qwen-flash` 对照方案。用户后来授权该方案；实际 T1 首次请求失败后按规则停止，详见[40 号记录](40-Day3百炼消息对照首次真实试验停止.md)。它不属于此前 10×3、50×5、100×10 的已用完授权，也不授权 500×30。

## 对照对象与输入

从[37 号只读审计](37-Day3消息对照候选离线审计.md)中固定第 4 轮 `agent_0019` 的局部观测。第 3 轮 `agent_0018` 的真实运行时消息 `msg_3_agent_0018_agent_0019` 是唯一被操作的因素。处理组保留该消息及其允许引用 ID；对照组只从 `received_simulated_messages` 和 `allowed_citation_ids` 删去它。两组的虚构证据、自身记忆、局部状态、人设、其他消息、系统提示、模型、`temperature=0` 和输出上界 256 均相同。历史 100×10 决策只用于选择候选，**不作为本次新对照的处理组结果**。

只允许纯合成字段外发。两组必须在派发前再次核对输入差异、冻结字段哈希、提示／适配器版本和准备发送 payload 的规范 JSON 哈希；保留每次请求的安全错误分类、usage 与费用。该哈希不是实际 HTTP 字节哈希。不得输出完整提示、消息正文、响应正文或密钥。

## 判读与限制

只有 T1/T2、C1/C2 均为有效决策，组内动作一致、两组动作不同，且处理组可核对引用了该消息时，才记为**该固定纯合成场景下消息影响动作的受控证据**。仅理由或引用文字不同、组内不一致、动作相同或任何请求失败，均记为未证实；不根据失败结果自动追加调用。即使取得受控证据，也不能外推到所有 Agent，更不能替代 500×30 的完整规模实测或使 G3 通过。历史 cutoff 继续按“首次有证据证明输入可见的时间 + 30 分钟”，本试验不涉及真实历史输入。

独立对照运行入口已完成无网络 dry-run 和预算／停止条件测试。首次授权下只尝试 T1，因 schema 失败停止，C1、C2、T2 均未发起。本方案的授权已结束；任何新真实对照须重新明确授权，不提交或部署。
