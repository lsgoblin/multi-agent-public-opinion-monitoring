# 本机工程交付文档

本目录整理当前代码可支持的本机部署、API、Web 操作和验证证据。它描述已实现与已记录的状态，不构成 G3、G4 或 G5 验收结论。

## 文档

1. [部署与运行](deployment.md)：主机与 Docker 启动、配置、数据持久化和已验证状态。
2. [API 参考](api.md)：当前 FastAPI 路由、请求约束、任务状态、报告/预警引用和错误语义。
3. [用户操作指南](user-guide.md)：案例准备、任务执行、进度、图谱、报告、预警和通知预览。
4. [测试与运行报告](test-report.md)：按批次区分的测试/运行记录、指标与验收缺口。
