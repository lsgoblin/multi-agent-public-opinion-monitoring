# Day 3 百炼混合模型离线接入记录

> 2026-10-06。状态：百炼北京地域的混合模型路由、计量与预算闸门已完成离线工程验证；**未向百炼发起请求，G3 仍未通过**。本记录不授权 Day 4、提交、推送或部署。

## 实现范围

- [Day 3 引擎](../../src/riskshield/day3.py)改为每个 Agent 决策前取得独立计价快照。`requested_model`、价格版本、保守预留、实际返回模型、输入/缓存输入/输出 tokens 和核销费用按动作保存，并按模型聚合到运行与轮次摘要。
- 同一轮中的两款模型请求先合并预留，再进入线程池。剩余额度不足覆盖整轮保守预留时，该轮不派发、运行标记 `partial`。缺失或无效 usage 时按该请求的保守预留核销，不记零费用。
- 引擎保留历史单模型后端兼容层。旧 SQLite `simulation_actions` 表会补充新列，新动作按显式列名写入，避免迁移后列序不同造成错位。
- [百炼适配器](../../experiments/day3_bailian_synthetic_backend.py)使用北京 OpenAI 兼容地址，固定映射网民/客户到 `qwen-turbo`，媒体/KOL/模拟监管到 `qwen-flash`，并显式发送 `enable_thinking=false`。引擎会拒绝同一 `run_id + agent_id` 在后续轮次改变请求模型。
- 适配器可从本机 `.env` 加载密钥、模型映射、价格版本、三类 token 单价和单次 token 上界；[配置样例](../../.env.example)不含密钥或未核实价格。真实后端拒绝零单价，因此免费额度或节省计划不会把任务成本记为零。不读取历史 DeepSeek 或通用网关密钥作为百炼凭据。
- 适配器默认禁用真实请求。只有调用方显式设置 `enable_live=True`、提供正数 `max_calls` 且配置百炼密钥时才可进入 HTTP 路径；本次没有这样调用。

## 离线验证

`tests/test_day3_bailian_synthetic_backend.py` 使用测试替身覆盖：

1. 临时 `.env` 加载与密钥不进入后端描述。
2. 500 Agent 中 200 个固定路由到 `qwen-turbo`、300 个固定路由到 `qwen-flash`；跨轮模型不变。
3. 缓存 token 计价、按模型聚合、请求模型与供应商返回版本分别记录。
4. 两款模型的并发预留共享一个预算闸门：低于整轮预留时零调用并 `partial`，等于边界时可派发。
5. 缺 usage 和后端异常都保留请求模型、价格版本、预留与失败类别，不保存供应商响应正文。
6. HTTP 函数由 monkeypatch 拦截，检查的外发结构只含虚构证据、匿名角色与参数、局部状态、本轮模拟消息、本 Agent 记忆、轮次和允许引用 ID。

完整回归命令：

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

结果：**67 passed, 1 warning in 17.48s**。warning 是既有 FastAPI `TestClient` 与 httpx 适配层的弃用提示，不是测试失败。测试中的模型价格和 usage 都是为验证账本而构造的数值，不是百炼价格、供应商回执或 G3 证据。
