## 3. AI 原生能力与不能替代的证据

新版要求 GraphRAG、独立人设/长期记忆、动态多智能体和可追溯；用户明确禁止预设脚本。按以下约束设计与验收：

| 要求 | 实现责任 | 可核验证据 / 不合格替代 |
| --- | --- | --- |
| 语义识别 | M02 | 模型输入输出与标签评测；关键词匹配不能独立冒充语义识别 |
| GraphRAG 真正参与推演 | M03、M04、M06 | 检索到的实体关系/来源及被使用的记录；只有图谱截图不够 |
| 独立人设与长期记忆 | M04、M05 | 不同局部观测与可恢复记忆，跨轮检索和行为变化；共享一段提示不等于 500 个独立 Agent |
| 运行时社会交互 | M05 | 本轮动作改变下一轮可见消息和状态，实际模型调用与动作校验；预设时间线、固定曲线、复制轨迹不计 |
| 可解释报告 | M06、M07 | 图、曲线与结论来自本次轨迹并有原始来源；单次长文生成不能冒充仿真 |

正式评分权重尚未提供；取得后再补各得分项，不按未确认权重调整当前指标。
