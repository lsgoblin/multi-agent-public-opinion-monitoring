# 走势标签执行口径提案 v5（待主 Agent 冻结）

## 来源层级

- **命题明确要求**：走势评测使用真实历史事件和真实后续证据；cutoff 后材料不得进入预测输入；多个来源不能冒充多个事件；不确定时不伪造标签。
- **已确认项目规则**（AGENTS.md）：cutoff 以可复查的首次可见证据加 30 分钟；来源保留使用范围、时间、版本和覆盖；多个来源/帖子不自动成为多个事件；投诉帖不代表公司全渠道投诉量；未来结果和标签不进入图谱、记忆或推演。
- **内部暂定方法**（需主 Agent 确认）：用等长 `7×24h` 窗口整理材料。基线 `[cutoff−7d, cutoff)`；观察 `(cutoff, cutoff+7d]`。该窗口不是主办方硬性要求。

## 指标与标签

预测对象是**公开讨论关注度走势**，不是业务是否恢复，也不是公众态度真值。情感分布由独立人工抽样记录，不与讨论量合并。

- 每个窗口使用相同来源族、查询式、抓取/存档方法和去重口径，逐条保存来源发布时间与观察时间。按事件而非 URL 去重；同一事件的转载、回复和不同社区帖子不增加事件数。
- 若有连续记录，报告各来源族的去重讨论条数/日；报道条数只能称为“传播热度代理”，不称为全平台舆情或公众情绪真值。
- 内部方向建议：两类独立来源族均高于基线且至少有一项可比量化信号上升，才标 `escalate`；均低于基线且没有反向信号才标 `calm`；两窗均有充分可比信号且差异落在冻结容差内才标 `stable`。
- 供主 Agent 冻结的**内部数值草案**：以同来源族、同查询所得的去重公开讨论条数计算窗口日均值；后续/基线比值 `≥1.5` 作为升温、`≤0.67` 作为降温、其间作为无明显变化。任一窗不足 5 条、基线为零或来源覆盖不匹配时标 `unknown`。两类独立来源族须同向，且至少一类是公众讨论来源；媒体报道只能作传播热度代理。
- 上述比值和 5 条覆盖线**未获确认、不用于本批标签、不是项目验收阈值**。主 Agent 冻结前不计算或发布正式方向；不得根据预测结果选阈值。缺日、覆盖变化、仅有公司回复/法律或业务结果、或方向冲突时同样标 `unknown`。
- 公司撤回政策、结案、恢复服务、没有新报道或停止发帖均不能单独证明 `calm`。方向标签需记录同向证据、反向证据和覆盖差异。

## 事件身份与盲评

同一主体/政策/交易/事故/诉讼/争议链按一个事件计；不同作者、URL、平台或转载不增加事件数。只有独立起因与可区分时间线的不同事故/诉讼才另计。选样只看证据完整度和任务适用性，不看模型输出。

预测输入只引用 cutoff 前材料。后续来源和方向标签放在 `labels/trajectory-evidence-v5.json`。情感包保留原帖标题；标注者分别提交标签、理由、时间、版本和预测暴露自报。预测与标注互盲；分歧保留原答后交独立裁决。

## 当前样例结论

FNF 与 Louisiana BCBS 交易均有 cutoff 输入和多个时点的后续公开讨论证据；两者都缺同口径可比讨论量基线，走势暂为 `unknown`。Louisiana 交易撤回是窗口后的业务结果，不能标成平息。人工标签尚未回收，E 的预测和评分状态分别是“等待 E 预测”与“等待协议/人工标签”。
