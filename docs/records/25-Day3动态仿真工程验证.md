# Day 3 动态仿真工程验证记录

> 2026-10-05。状态：Day 3 本地工程、测试替身规模验证和一次纯合成小规模真实模型验证完成；**G3 未通过**。本文不代表真实模型完整规模验收或 Day 4 授权。

## 实现范围

[Day 3 引擎](../../src/riskshield/day3.py)实现以下链路：

1. 创建网民、客户、媒体、KOL、监管五类角色；每个 Agent 保存独立 persona、邻居和局部情绪/信任状态。
2. 记忆、消息、状态和动作按 `run_id + agent_id` 持久化到 SQLite；新运行默认不继承旧运行数据。
3. 每轮先一次性冻结所有 Agent 的状态、截止前证据、上轮收件箱和自身记忆，再进入受控线程池决策；轮内完成后统一传播消息、更新状态并写入记忆和轨迹。
4. 决策只允许引用本 Agent 当前可见的证据、消息或记忆；未知引用、其他 Agent 私有记忆和图中的截止后/非输入材料被拒绝或记为显式失败。
5. 运行保存配置人数、实际参与人数、逐轮请求/活跃/失败/消息、模型标识、token usage、费用和 `complete`/`partial` 状态。真实模型后端必须声明单请求保守预留；余额不足时整轮派发前停止。
6. API 新增 `POST /simulations`、`GET /simulations/{run_id}` 和 `GET /simulations/{run_id}/trajectory`。当前 API 只创建和读取运行；没有获准的 Day 3 模型后端，因此不会隐式发起云端请求。

## 因果、恢复与隔离验证

[Day 3 测试](../../tests/test_day3_simulation.py)使用明确标记为 `test_substitute` 的响应式替身。首轮由角色和局部证据产生动作；后续轮若收到新消息则改为评论，若只有自身历史记忆则改为求证。3 Agent × 2 轮测试的首轮动作是 `share / observe / observe`，重启进程并从同一 SQLite 恢复后，第二轮变为 `seek_clarification / comment / comment`。轨迹分别包含触发行为的 memory ID 或 message ID。

同一测试还验证：新 run 首轮收件箱和记忆均为空；每个 Agent 只检索到 ID 含自身 `agent_id` 的记忆；未知私有引用产生 `SimulationError` 失败记录；包含 2024-03-08 后续结果的图不能创建运行。测试替身不等于真实模型动态行为证据。

## 小规模真实模型验证

用户另行明确授权 DeepSeek 纯合成小规模验证后，于 2026-10-05 执行 10 Agent × 3 轮、并发 3、最多 30 次请求的真实运行。后端固定 `deepseek-flash`、非思考模式、无重试、每次最多 1,200 输入和 160 输出 tokens，只发送匿名角色和参数、局部状态、虚构证据、收到的模拟消息、自身模拟记忆、轮次及动作 JSON 约束。没有发送 UnitedHealth、SEC、Optum、URL、账号、run ID、cutoff、邻居表、其他 Agent 私有记忆或凭据。Day 3 DeepSeek 执行代码已从当前工程移除；脱敏运行结果仍保留为[JSON 证据](../../data/research/day3_synthetic_deepseek_validation_20261005.json)。

运行结果为 `complete`：30/30 有效决策，10/10 Agent 实际参与，3/3 轮完成，0 失败；供应商回执为输入 8,817、输出 1,647、合计 10,464 tokens，响应模型 `deepseek-flash`。按[Day 2 已记录价格基准](16-Day2DeepSeek受限情感初测.md)的峰值缓存未命中输入 $0.30/百万、输出 $1.20/百万和 8 元/美元估算为 **¥0.036972**，低于本次 ¥0.13248 授权上限；这是回执 token 的估算，不是供应商账单。

轨迹审计显示：三轮动作均为 9 个 `observe`、1 个 `seek_clarification`；第二轮 10 个 Agent 均检索到自身记忆、9 个决策引用 memory ID，第三轮 10 个决策均引用 memory ID。但没有 Agent 改变动作，也没有产生传播消息。因此本次验证证明真实模型协议、独立上下文、记忆送入和引用校验可运行，**没有证明“新消息或记忆改变后续行为”**。

按本次实际平均估算费用 `¥0.036972 / 30 = ¥0.0012324` 外推，15,000 次同类调用约 **¥18.486**，明显超过执行时的 ¥2.36 上限，也超过后来提高的 ¥5.00 上限；这只是样本均价线性外推，不是报价或账单。消息字段对照和稀疏激活方案见[后续离线测算](26-Day3消息对照与稀疏激活测算.md)。该 DeepSeek 样本不能证明全员逐轮云调用可在当前 ¥30.00 预算内完成。
