# 走势评分口径提案 v6（供主 Agent 冻结）

状态：**内部可执行建议，尚未批准；不可据此发布正式走势标签。** 本提案把命题、项目已确认规则和本轮建议分开。

## 1. 规则来源

**命题明确要求**：使用真实历史事件；预测输入与 cutoff 后结果隔离；按独立事件计数；情感与走势不能混为一项；证据不足时不伪造方向。

**已确认项目规则**：历史 cutoff 采用可复查的首次输入可见时间加 30 分钟；来源须记录使用范围、时间、版本和覆盖；多来源/多帖子不增加事件数；未来材料不进入预测、图谱、记忆或推演；个人投诉不代表公司全渠道投诉。

**本轮待确认内部方法**：以公开讨论关注度作为走势对象；采用下列等长日历窗口、来源覆盖门槛及方向阈值。主 Agent 可批准或改定，不应把这些草案写成主办方硬性要求。

## 2. 事件与窗口

- 同一政策、交易、事故、诉讼或争议链按一件事件计。转载、作者、URL、频道或来源条数不构成新事件。
- cutoff 继续使用已确认的“首次输入可见时间 + 30 分钟”，保留 UTC 原始时间与计算记录。
- 为兼容只提供日粒度的历史源，建议定义 `D0` 为 cutoff 所在 UTC 日：基线为 `D−7` 至 `D−1` 七个完整 UTC 日；观察窗为 `D+1` 至 `D+7` 七个完整 UTC 日；排除整个 `D0`，避免日桶把 cutoff 前后材料混在一起。样例：FNF 为 2023-11-16—22 对 2023-11-24—30；Louisiana 为 2024-01-30—02-05 对 02-07—13。
- 若来源保留逐条精确时间，可另按主 Agent 冻结的精确区间统计；不能把日粒度值伪装成 cutoff 时刻后的精确计数。

## 3. 指标与证据接纳

- 走势标签表示**公开讨论关注度**，不是业务恢复、赔付、法律结果或公众情感。
- 每个平台/来源族预先固定查询式、地理/频道范围、去重方法、归档版本和抓取范围。两窗必须使用同一配置。
- 计算各来源族每个有效覆盖日的独立事件相关讨论单位数；报告原始数、有效覆盖日、日均值和变化比。只对同一来源族作前后比较，不把不同平台原始计数直接相加。
- 建议方向判断至少需要两个独立来源族在两窗均有可比覆盖，其中至少一个必须是公众讨论来源。新闻报道或电视字幕只可作为**传播热度代理**，不能单独代表公众讨论或公众情绪。
- 建议每窗至少覆盖 6/7 日；用于方向判断的公众讨论来源每窗至少有 5 个去重单位。低于门槛、基线为零但来源并非穷尽、查询/覆盖变化、缺少发布时间或证据冲突时标 `unknown`。
- 公司回应、结案、政策撤回、业务恢复、诉讼进展、停止发帖或“没有搜到材料”均不能单独证明平息。只有在同一已知完整覆盖范围内，后续讨论量确实下降且没有反向来源，才可考虑 `calm`。

## 4. 方向阈值草案

对每个来源族分别比较观察窗与基线的日均值；不跨来源合并计数。

- `escalate`：至少两个合格来源族均达到观察/基线比 `≥1.5`，且无合格来源族明显下降。
- `calm`：至少两个合格来源族均达到比值 `≤0.67`，且来源覆盖完整、无反向证据；零值只在可证实完整覆盖时有效。
- `stable`：至少两个合格来源族均有足够样本且比值处于 `0.67—1.5`，无明显相反走势。
- `unknown`：任一数据/覆盖条件不满足，或来源族结论相反。不得为凑足样本量强行归类。

`6/7 日`、`5 个单位`、`1.5/0.67` 都是**内部数值建议**，待主 Agent 冻结，不是命题阈值。电视字幕百分比若只在部分频道/时段有可比覆盖，只能作为独立代理证据并报告具体覆盖，不足以替代公众讨论来源。

## 5. 人工判定与隔离

- 情感标注单位是冻结 cutoff 前标题或正文，按原始表达标 `positive / neutral / negative / uncertain`；不判断事实真伪。
- 走势证据包只给两名独立标注者看冻结窗口内的来源、时间序列、脱敏片段、基线/观察值、反向证据和规则；隐藏 E 预测与另一位答案。
- 两人原答、理由、标注者 ID、时间、版本和预测暴露情况分别保存。分歧按主 Agent 冻结的裁决规则处理，不能覆盖原始答案。
- 未来走势证据和人工标签仅供预测封存后的评分侧读取，绝不回填预测输入、Store、图谱、Agent 记忆或提示词。
