# 最终离线评测内部执行协议 v2

> 冻结于 2026-10-08（北京时间），在新增模型预测输出前定版。此为项目内部复核方法，**不是主办方确认口径**。新版命题中的阈值原样保留；任何预测封存后不得调整事件、窗口、阈值、样本资格或排除规则。

## 身份、输入隔离与封存

1. 走势以底层事件 `event_id` 去重，同一事件的多个来源、帖子、case 或运行不得扩大事件分母。仅 `holdout` 进入正式汇总；`holdout_candidate` 只作工程/候选记录，直至正式接纳证据随新交接冻结。
2. 独立预测进程只读取最新完整 E handoff 指定的 `predictor_execution_read_allowlist`。逐项核验 handoff、freeze 成员、字节数和 SHA-256。cutoff 输入任何实质变化，须重新运行并封存；不得复用旧输出。
3. 预测端拒绝评分材料。提交给模型的来源时间必须可解析、有时区且不晚于 cutoff；`evaluation_only`、未知可见时间、后续结果、人工标签及 AI 参考标签不得进入提示、图检索或记忆。
4. 预测输出、输入、模型/执行模式、参数、提示版本、协议和代码哈希均写入新批次封存。仅在封存后，评分进程才能读取评分侧证据/标签。离线基线或替身只属于工程验证。

## 走势窗口与方向

- cutoff 所在 UTC 日期为 D0，排除 D0；基线窗为 D−7…D−1，观察窗为 D+1…D+7，均为完整 UTC 日。固定查询、平台/来源族、分页、去重方式和抓取时刻。
- 每窗口至少 6/7 个有效日，且同口径公众讨论主单位至少 5 个去重单位；需要两个独立、可比来源族，其中至少一个为公众讨论来源。新闻、电视字幕、搜索热度只能单列为代理，不能自动等同全平台公众讨论走势。
- 每个合格来源族的观察/基线日均比均 ≥1.5 时标 `escalation`，均 ≤0.67 时标 `calming`；中间范围、来源冲突、零基线、归档覆盖未知、截断或明显混杂标为 `stable`/`unknown` 并排除一致率分母。仅 `escalation` 与 `calming` 可配对计算方向一致率。
- 人工走势标签须由两位独立真人对同一冻结证据包盲标并保留原答、时间、版本与预测暴露声明；分歧须先裁决。AI 标签不构成人工走势真值。

## 情感单位与 AI 参考比较

- 情感按冻结的原始标题或帖子单位评分；事件摘要、报告摘要和传播代理不能替代原文。预测、人工标注与来源须通过相同单位 ID、来源 ID 和原文 SHA-256 对齐。
- 正式情感三分类只接受 `positive / neutral / negative` 中两份独立、一致、未见预测且可追溯至同一原文的真人标签。缺失、分歧、未裁决、`mixed`、`unclear` 或其他未定义标签不填造，逐项列出排除原因。
- AI 标签可单列“与 AI 参考标签一致率”及混淆矩阵，仅作探索性模型间一致度。须通过原文单位、原文哈希、预测输出哈希和来源 ID 对齐；`needs_review` 单位排除。AI 参考分子/分母不进入真人情感、负面识别或主办方达标指标。

## 分母、指标与工程要求

- 报告情感三分类正确数/合格原文单位数及 3×3 混淆矩阵；负面识别分别报告 TP、FP、FN、TN、precision、recall 和 binary accuracy。主办方尚未明确“负面识别准确率”公式，两个候选口径并列报告，不代为选择。
- 报告走势正确事件数/合格独立事件数、2×2 混淆矩阵、unknown 与所有排除原因。走势和情感资格分别核验，一项缺标签不得屏蔽另一项可算分指标。
- 500×30 必须同时报告 15,000 次机会、已派发、有效、失败、未派发、完整轮数与事件输入至报告写盘的完整耗时。请求全部结束不等于全部决策有效。≤60 分钟只以相同完整链路的真实计时判断，仿真阶段耗时不能替代。
- 每份报告校验同一 `case_id / graph_id / run_id`、五个模块、执行模式、来源 ID 和可复核哈希。零分母指标写“不可计算”并给出缺项，不写 0% 或达标。
