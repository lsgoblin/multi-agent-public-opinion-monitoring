# 公开舆情数据方案

> 更新：2026-10-02。适用新版命题；实际来源状态与事件证据见[11](../records/11-Day1初始数据采集与审计.md)。

## 数据目标

分别准备三类材料：情感三分类标注集、真实事件的 cutoff 输入和后续方向证据、五平台在线覆盖与延迟记录。历史投诉是可选事件种子，不需要投诉日序列。搜索结果不算平台完整覆盖，转载不算独立事件。

## 采集与入选

1. 逐源核查微博、抖音、小红书、黑猫、新闻门户的访问与使用条件、时间精度、去重和失败。黑猫样本用途已由用户确认；其他来源分别判断。
2. Day 1 先取得一个有可核查公开可见时间的真实事件。20 个独立候选仅为后续内部收集目标；正式回测事件数待赛题方明确。
3. 来源记录保存平台、源 ID/URL、主体依据、脱敏内容、published_at、证据支持的 available_at、collected_at、时间精度、版本和用途。未知可见时间保持未知，不用发起、审核或今天的截图倒填过去。
4. 历史推演暂取首次有证据证明可见的时间后 30 分钟为 cutoff；逐条过滤输入，之后的回复、结案和走势材料只作后续证据。目标结果若在 cutoff 前发生，该事件不用于这一预测设定。
5. 情感与走势标签由独立人工证据形成；单条投诉办结不等于整体舆情平息。按事件划分开发与留出集，不能让后续标签进入 GraphRAG 或 Agent 记忆。

在线采集延迟须真实在线观测；历史导入不能计入五平台或 15 分钟指标。
