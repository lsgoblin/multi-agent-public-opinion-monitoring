# 模型、预算与域内路线

> 更新：2026-10-02。当前是 Day 1 可行性方案；实际探测记录见[12](../records/12-Day1DeepSeek接入与探测记录.md)。

## 已验证与未验证

DeepSeek V4.1 Flash 已完成一次纯合成、结构化真实 API 调用：372 tokens、2.56 秒。它证明协议和输出契约可用，不证明真实舆情识别、动态仿真、500×30 吞吐或域内运行。模型网关必须记录实际模型、各阶段 token 用量、耗时、证据引用和失败；不回显密钥。

## 完整任务预算

按 500 Agent × 30 轮、全员每轮决策的上界，共 15,000 次决策机会；不必等于 15,000 次 HTTP 请求。包含构图、记忆与报告的粗估如下，尚无全链实测：

| 上下文假设 | 完整任务 tokens |
| --- | ---: |
| 精简 | 约 2,048 万 |
| 基准 | 约 4,030 万 |
| 较长 | 约 6,045 万 |

用户确认**单次完整任务费用硬上限 ¥2.38**。历史账单 1,234.16 万 tokens / ¥1.47 的有效单价，条件外推 2,000 万 tokens 约 ¥2.38；账单未给出输入/输出与缓存拆分，不能据此保证未来价格。按相同有效单价，基准情景约 ¥4.80，提示 500×30 与费用上限可能冲突。后续分级测量真实用量，控制活跃决策和上下文长度，预留报告预算；触及上限停止新请求并标 partial，不能把未完成任务报为规模达标。

## 两种运行边界

- 开发：在获准内容范围内可用云端 DeepSeek；调用会离开本机，不能算数据不出域。既有探测只含合成文本。
- 域内交付：模型推理、可选嵌入、GraphRAG 图/记忆、数据库、日志和 Web 资源均在允许边界内；图数据先评估 SQLite，只有检索质量或性能需要才增加图/向量服务。当前本机为 Ryzen 7 8845HS、约 31 GiB 内存及集成显卡，未证明本机能承担最终规模；域内模型/设备仍需平台方提供或确认。

Day 1 要求的是可评审路线。Day 2—4 再按小规模到 500×30 逐级验证延迟、费用和无外发；Docker 文件本身不证明域内合规。
