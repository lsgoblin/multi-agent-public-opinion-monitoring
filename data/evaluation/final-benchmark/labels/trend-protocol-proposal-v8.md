## 命题明确要求

- 以真实历史事件为对象，按独立底层事件计数；cutoff 后信息不得进入预测输入。
- 走势预测与情感分类分开；真实人工标签独立于预测，证据不足或冲突时保留未定。
- 后续结果只在预测封存后由评分侧读取。

## 已确认项目规则

- 来源留存使用范围、发布时间/可见时间、版本和覆盖证据；未知可见时间不进入 cutoff 输入。
- 投诉帖不代表公司全渠道投诉量；同一事件多帖/多来源不能增加事件数。
- 结案、业务恢复、诉讼/赔付结果、停止发帖或检索无结果都不能单独证明舆情平息。

## 内部暂定方法

1. **窗口**：令 cutoff 所在 UTC 日期为 D0；基线为 D−7 至 D−1 七个完整 UTC 日，观察为 D+1 至 D+7 七个完整 UTC 日，排除整个 D0。若采用精确 cutoff±7×24 小时，须另行冻结，不与日粒度窗口混算。
2. **测量**：预先固定查询词、语言/地域、平台/来源族、去重、分页/响应上限和抓取时刻；帖子与评论分别报告。每项给出逐日结果、窗口去重总量、覆盖日、重复行及上限。新闻篇数、电视字幕和搜索兴趣只称传播/检索热度代理，不是情绪真值。
3. **可比性建议**：同一来源族、同一查询和同一检索范围比较前后。现有 v7 草案要求两个来源族各自可比且至少一个为公开讨论源；但 State Farm 试点只有一个 Reddit 归档来源、两个独立报告指标，主 Agent 需决定它能否成为正式走势证据，或必须补齐第二来源族的可比基线和观察序列。
4. **覆盖与样本建议**：每个窗口至少 6/7 个有效日；主公开讨论指标每窗至少 5 个去重单位。零基线、未知归档完整度、检索召回/覆盖发生变化、窗口触顶或证据冲突时先标 unknown。以上门槛待主 Agent 核定。
5. **方向建议**：每个来源族独立计算观察窗/基线日均值比，不跨平台求和。仅在至少两个合格来源族方向一致且无明显反向证据时考虑升级（均≥1.5）或平息（均≤0.67）；比值处于 0.67—1.5 可考虑稳定；低样本、零基线或来源分歧为 unknown。阈值不是命题硬要求。
6. **人工标注**：冻结规则后，由两位独立标注者仅看截止窗口、覆盖/反向证据和脱敏摘要，不看预测与他人答案；分别记录方向、理由、人员ID、时区时间、材料版本、预测暴露。保留原答，分歧交主 Agent 冻结的独立裁决规则处理。
