# Day 3 百炼混合模型 100 Agent × 10 轮分级试验

> 2026-10-06。用户授权的 10×3、50×5、100×10 三档纯合成百炼实验已分别执行；本记录只说明第三档。脱敏[运行 JSON](../../data/research/day3_synthetic_bailian_100x10_20261006.json)与本地 SQLite 保留供审计。**100×10 有 27 次失败，不是 1000 个有效决策；G3 未通过。**

## 执行边界与离线准备

- 100 个 Agent 中 40 个固定路由到北京 `qwen-turbo`、60 个到北京 `qwen-flash`；10 轮共 1000 次决策机会。显式 `max_calls=1000`、并发数 4、预算 ¥5.00，没有自动重试。百炼适配器只允许虚构事件、匿名角色／局部状态、运行时实际消息、该 Agent 自身记忆、轮次和允许引用 ID 外发；没有真实 SEC、Optum、黑猫材料、账号、个人信息、其他 Agent 私有记忆或密钥。
- 在[50×5 后期失败](35-Day3百炼混合50x5分级试验.md)后，离线把 `qwen-flash` 输出上界从 160 调到 256，`qwen-turbo` 仍为 160，并将结束原因、JSON 语法、决策 schema 和响应形状分类为不含正文的安全错误类别。全量离线回归 **95 passed, 1 warning**。该改动是缓解和诊断，不能证明此前错误均由截断造成。
- 只读预检确认专用密钥、北京端点、两模型价格及固定路由。按 8,192 输入与各模型输出上界、阿里云官方[`qwen-turbo`](https://help.aliyun.com/zh/model-studio/qwen-turbo)和[`qwen-flash`](https://help.aliyun.com/zh/model-studio/qwen-flash)北京标价，本档保守预留 **¥1.98912**，低于 ¥5.00。相同上界下 500×30 的纸面保守预留变为 **¥29.8368**，距 ¥30.00 仅 **¥0.1632**，不保证覆盖其他任务费用或最终完整规模。价格版本标签是本地核对日期，不锁定供应商报价。

## 真实运行结果

| 项目 | 结果 |
| --- | --- |
| 请求与轮次 | 1000/1000 次决策机会已尝试，10/10 轮执行完毕；`run_status=complete` |
| 有效与失败 | **973/1000** 有效、**27/1000** 失败；`completed_without_failures=false`。`qwen-turbo` 为 399/400，`qwen-flash` 为 574/600 |
| 安全失败类别 | `qwen-flash` 决策 schema 不符 **26** 次；`qwen-turbo` 输出长度结束 **1** 次。没有保存供应商响应正文，无法事后判定 26 次 schema 失败的具体字段 |
| 供应商 usage | 成功请求合计输入 **459,695**、缓存输入 **256**、输出 **94,655** tokens；`unknown_usage_calls=27` |
| 本地费用 | **¥0.25447011**，包含 27 次失败的 **¥0.0444864** 保守预留；这是任务账本估算，不是供应商最终账单 |
| 动作与传播 | `observe` 482、`share` 155、`comment` 310、`seek_clarification` 26；持久化运行时消息 **1395** 条 |
| 跨轮输入与引用 | 597 次有效决策的观测含上轮消息，其中 84 次引用了消息 ID；后续轮次有独立自身记忆输入。但没有移除消息的真实模型对照，不能声称消息导致动作改变 |

第 1—2 轮各 100/100 有效；第 3—10 轮均有失败，最少第 5、6 轮各 94/100 有效。`qwen-flash` 有效决策的理由长度最高达到 schema 当前上限 500 字符，26 次 schema 失败可能涉及长度或其他字段；在没有响应正文及安全字段分类前，不作根因推断。提高输出上界后仍出现失败，因此不能据此声称后期输出问题已解决。

三档分级实验的单次授权均已用完。100×10 的规模配置和轮数已真实运行，但含失败；500×30 云端运行未获授权，严格消息因果未验证，数据不出域与正式赛题指标也未由此证明。测试替身、含失败的 `complete` 和预算触顶 `partial` 均不算 G3 通过。历史 cutoff 继续采用“首次有证据证明输入可见的时间 + 30 分钟”，本次纯合成试验不改变该规则。**G3 保持未通过，不进入 Day 4。**
