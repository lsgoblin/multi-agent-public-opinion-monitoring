# 最终离线评测内部执行协议 v1

> 冻结于 2026-10-08（北京时间），早于 E 的本批预测输出。此为项目内部可复核方法，**不是主办方确认口径**。不得根据预测结果改变窗口、阈值、样本或排除规则。命题阈值仍以[新版命题](../sources/2026-09-30-新版命题-多智能体仿真舆情监测.md)为准。

## 身份、隔离与顺序

1. 一件底层舆情事件只计一个 `event_id`；同事件的来源、帖子、case 或多次运行不能增加走势分母。`holdout_candidate` 保留待接纳状态，不自动算正式事件。
2. 预测端仅按最新完整 `e-handoff` 的 `predictor_execution_read_allowlist` 读取 cutoff 输入，先核验清单和原文件 SHA-256。来源须有时区明确且不晚于 cutoff 的 `available_at`，未来结果、标签、未知可见时间不进图、记忆或预测。输入实质变化须重新预测。
3. 先封存预测、输入、配置、执行模式和代码哈希，再由独立评分步骤打开后续证据与人工标签。封存后不得改预测；新批次另建输出。离线固定基线只证明流程隔离，不代表真实模型表现或正式预测达标。

## 走势观察与标签资格

- cutoff 所在 UTC 日期为 D0，排除 D0；基线为 D−7 至 D−1，观察为 D+1 至 D+7，均为完整 UTC 日。每事件固定查询词、来源范围、分页、去重方式及抓取时刻。
- 同一来源族比较相同查询与范围的去重公开讨论单位，帖子和评论分别报告，不跨平台相加。每个窗口至少 6/7 个有效日且主讨论指标至少 5 个去重单位；要求两个独立、可比的来源族，至少一个是公众讨论源。零基线、归档覆盖未知、截断、明显混杂或反向证据均记 `unknown`，先补证而不硬判。
- 对每个合格来源族计算观察/基线日均比；两来源均 ≥1.5 才可标升级，均 ≤0.67 才可标平息。中间为稳定，来源冲突或资格不足为 `unknown`。稳定和 unknown 不转写成升级/平息；方向一致率仅用事前已封存的 `escalation`/`calming` 预测与合格同类结果配对。
- 新闻篇数、电视字幕和搜索热度仅为传播代理，不能自动当作全平台公众讨论走势或公众情绪。业务恢复、交易撤回、无搜索结果不能单独证明舆情平息。
- 走势真值须由两位独立真人在盲态下按同一冻结证据包标注并留原答、时间、版本与预测暴露。分歧待独立裁决；AI 标签不计为真人标签。无资格或无标签的事件逐项写排除原因。

## 情感与统计

- 情感单位是冻结的**原始标题或帖子**，不把事件级 `input_text` 摘要当作原始情感单位；与走势资格独立核验。两位独立真人一致且未见预测才形成当前可计分真值；缺项或分歧不填造。
- 报告三分类正确数/可计分原始单位数、三乘三混淆矩阵；负面识别同时报 precision、recall 和二分类 accuracy，因命题“负面准确率”公式未确认，不替主办方选定。各项分别给分子、分母、排除原因。零分母写“不可计算”，绝不写 0%。
- 逐事件/逐单位结果、样本量、执行模式与版本哈希随评分产物保存。试点、工程替身和正式可评分结果分开；不足样本不宣称总体指标达标。
