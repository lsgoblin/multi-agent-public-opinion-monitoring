# 用户操作指南

## 使用范围

当前 Web 工作台能处理纯合成案例，或对已有、cutoff 可核验的真实历史材料运行本机 `offline_dynamic_substitute`。后者保留真实来源和时间证据，但推演本身不调用真实模型。报告自然语言追问另有默认关闭的百炼北京 qwen-turbo 入口，只有服务端配置了明确授权的案例、预算和凭据才可调用。企业微信和邮件只有 `dry_run` 预览，没有发送动作。

服务启动方式见[部署与运行](deployment.md)。主机模式打开 `http://127.0.0.1:8501/`；已实测 Docker 项目 `riskshieldaccept` 的 Web 为 `http://127.0.0.1:18501/`。页面左侧当前包含“处置队列”“今日概览”“事件证据”“五模块报告”“预警中心”和“关口状态”。

## 1. 准备并核对案例

1. 进入“事件证据”。若案例列表为空，可导入页面提供的随附事件包；选择案例后核对 `data_mode`、版本、cutoff 和 cutoff 依据。
2. 查看“截止前输入”及排除统计。只有可证明在 cutoff 时已公开可见的输入候选才可进入图和 Agent 上下文；未知可见时间、未来材料及 `evaluation_only` 记录不得混入输入。后续证据复选区是评测展示，不会输入 Agent。
3. 真实历史案例任务仅接受本机已有的 `real_historical` 案例和可核验的归档输入。此任务不是在线回采。若记录没有观察行，实现会尝试构建 `offline_archived_record_projection`；请在报告中核实 `graph_build_mode`，不要把本地图投影称作在线 GraphRAG 检索。
4. 纯合成案例用于功能演示；随附 Harborlight 演示为虚构保险服务事件。合成材料不应与真实历史来源拼成一份真实事件报告。

## 2. 准备和启动任务

### 连续演示：历史案例、报告与预警

1. 在“事件证据”点击“导入多来源历史事件”。固定演示案例为 `unh_change_20240222_day2_multisource`，来源版本为 `unh-day2-multisource-2026-10-04-v1`，事件包为随附的 `data/public/unh_change_20240222_day2_multisource_event.json`。若数据库已有其他案例，在列表中选择这个 ID。
2. 核对 cutoff 为 `2024-02-22T16:48:39-05:00`（北京时间 2024-02-23 05:48:39），截止前输入有 2 条归档来源，排除统计中 `not_input=1`。勾选后续证据只影响评测展示。
3. 在“处置队列”的“手工配置”选择该案例，使用页面默认的 10 个智能体、3 轮和并发 4，启动离线任务。执行使用本机 `offline_dynamic_substitute`，不联网采集，也不调用云模型。
4. 选中任务并点击“刷新任务进度”。完整执行应有 3/3 轮、30 个有效决策、0 个失败决策和 10 个实际参与智能体。仿真任务的云模型调用和外部网络请求字段均为 0；这些字段不包含独立的报告追问调用，后者有自己的费用账本。
5. 从任务直接点击“打开关联图谱”“打开关联报告”或“打开关联预警”。在技术字段中记录 `case_id → graph_id → run_id → job_id → report_id → alert_id`；运行、任务和报告/预警 ID 会随新任务变化，无需沿用历史演示的 ID。
6. 在报告中查看来源证据图、模拟传播图、情绪/动作曲线、节点排序、风险和业务建议。来源图范围展示案例、cutoff 和版本；固定案例的 `graph_build_mode` 应为 `offline_archived_record_projection`。“按词项查找引用来源”返回匹配材料；独立的“自然语言追问”入口见下文。
7. 在预警页核对暂定离线判级，分别选择“企业微信”和“邮件”生成 `dry_run` 预览。核对预览的预警 ID 与当前任务一致，`sent_at=null`。

此离线流程使用本机已有的归档材料，不代表真实走势预测或命题验收达标。主动提交获准的自然语言追问会向百炼发送限定证据和对话；浏览器打开来源链接只供人工核对，页面新内容不进入 cutoff 上下文。

### 纯合成快速演示

1. 在“处置队列”展开“准备或创建任务”。
2. 点击“准备离线演示任务”。页面创建固定 10 Agent × 3 轮、并发 4 的纯合成运行配置；此时尚未执行。
3. 在队列选中该运行，核对案例为虚构 Harborlight 场景、数据模式为 `synthetic`。
4. 点击“启动本机离线任务”。这是启动后台任务的动作；执行使用 `offline_dynamic_substitute`，不会调用云模型或外部网络。

### 真实历史材料离线任务

1. 在“处置队列”的“手工配置”选择已核对的真实历史案例。
2. 设置 Agent 数量（1–100）、轮数（1–10）和并发（1–32）。
3. 点击“启动真实历史事件离线任务”。该入口会尝试建立截止证据图，创建运行并排入替身执行；图谱/材料校验不通过时会失败，不会跳过验证继续推演。
4. 完成后核对案例、图谱、数据模式、执行模式和来源版本。真实历史材料只描述输入来源；输出依然是离线替身仿真，不是真实走势预测。

### 其他本地配置

对非 `real_historical` 案例，可先点击“为所选案例构建截止证据图”，核对图 ID，然后创建本地运行配置。界面提供 1–500 Agent、1–30 轮、1–128 并发和最高 ¥30.00 费用上限字段。此操作只创建运行；从队列再点“启动本机离线任务”才进入本地后台执行。费用上限是约束字段，不代表实际成本已经测得或达标。

## 3. 查看进度和处理失败

- 处置队列可按全部、运行中、待启动、已完成、部分完成和失败筛选；选择运行后查看 `run_id`、进度轮数、实际参与人数、运行状态、图 ID、数据模式和费用估算。未产生有效决策时，实际参与人数为 0，配置人数在手工配置中核对。
- 在“执行进度”点击“刷新任务进度”读取最新数据库状态。页面**不会自动轮询**。
- 执行任务状态为 `queued`、`running`、`complete` 或 `failed`。`result_state` 细分成功、部分完成、停止和失败；只有全部决策有效的 `complete` 才自动生成报告和预警，并显示关联产物。部分完成或停止时页面显示受限类别、决策计数，不显示异常堆栈。
- 即使全部轮次已结束，只要 `all_decisions_valid=false`，队列仍显示“部分完成”，归入对应筛选；完成轮次或 100% 进度不表示完整成功。有效和失败决策直接读取动作账本计数。
- 常见失败类别包括 `data_integrity_error`、`simulation_error`、`alert_error`、`report_error`、`thread_start_error`、`unexpected_error` 和服务重启后的 `interrupted_on_restart`。后者不会自动续跑。核对案例/图谱 ID、数据模式、cutoff、来源版本和每条来源的可见时间，再按需要创建新运行。
- “一轮已结束”不等于所有 Agent 决策有效；“任务完成”也不等于命题指标达标。

## 4. 查看证据图与报告

1. 在任务详情点击“打开关联图谱”查看截止证据图。图中节点/关系表达来源与主张的证据关系，不是社交平台传播图。
2. 点击“打开关联报告”查看任务绑定报告；若对已有运行手动生成，可在“五模块报告”点击“生成离线报告”。
3. 检查报告概况、依据、五个模块和引用；各模块绑定相同案例、图谱与运行。模拟传播图默认聚焦一个发送智能体，可切换“全部智能体”；显示数与总数分别列明，完整关系及引用保留在明细。模拟消息数不证明因果影响。情绪曲线是仿真状态重建或动作分布代理，不是现实公众情绪。
4. “来源证据检索”按词项匹配标题/摘要，返回来源引用和图邻域。“自然语言追问”结合模型理解问题和最近四轮有效对话，并逐轮核查报告、来源范围和逐字引用。
5. 从队列打开报告时，生成报告的运行选择会跟随该任务。通过技术字段输入另一个报告 ID 时，来源图与检索使用所查看报告自身的图 ID；旧图或旧查询结果不会混入当前报告。

### 报告自然语言追问

1. 默认配置关闭该功能。明确取得模型、案例/来源范围和费用授权后，按 [.env.example](../../.env.example) 的 `RISKSHIELD_REPORT_QA_*` 配置启动 API；Web 输入不能扩大服务器白名单。凭据使用服务端 `DASHSCOPE_API_KEY`，不要在问题中粘贴密钥或材料文件。
2. 在报告下方确认案例、cutoff 和来源版本，输入问题后点“提交追问”。例如先问“截至截止时间，哪些系统受影响？”，再问“它们恢复了吗？”。本适配器只支持北京 qwen-turbo 非思考模式；问题上限 500 字符。
3. 回答显示来源/模拟报告/动作/消息的引用 ID 与逐字片段。来源引用可点击核对；模拟记录仅证明仿真账本。证据不足时显示弃权，不补充未来恢复结果。引用校验失败或服务不可用时保留失败轮，不展示伪造的答案，也不会自动重试。
4. 对话在数据库中绑定报告和冻结证据摘要；浏览器会话内切换报告保留各自对话。重启 API 后可用对话 ID 从[追问接口](api.md#报告自然语言追问)读回；浏览器刷新后的新会话不会自动恢复此前对话。
5. 模型上下文仅含合格来源摘要、当前模拟报告摘要及少量首尾动作/消息引用，另附最近四轮有效对话。不发送整个数据库或评测结果。回答按普通文字显示，模型生成的 URL 不作为可点击链接。
6. 费用显示独立授权账本的已扣记/预留总额和调用次数。每次请求先原子预留保守上界，已返回用量按记录价格扣记；用量未知则保留预留。授权预算不得超过 ¥30；已用调用数、费用预留和失败不会因新建对话或重启 API 清零。此金额是 Token 用量估算，平台账单另行核对。

升级前生成的旧报告可能因报告结构变化无法通过冻结内容校验。此时为原运行点击“生成离线报告”，使用新报告开启对话；旧报告、对话和费用账本保留，不把旧对话迁移到不同报告，也不清空失败预留。

## 本机验证记录的解释

2026-10-14 第一轮证据通过 Streamlit `AppTest` 访问本机 API、后台执行器和隔离 SQLite，覆盖导入、配置、刷新、双图、报告、词项引用与两渠道预览。补充核验在实际浏览器中检查报告和引用，保存页面截图；SEC 链接打开原始 8-K，Optum 链接重定向到已更新页面，其新内容不进入截止输入。自然语言追问的离线多轮测试通过；三次真实调用未取得有效回答，其中两次明确返回 HTTP 429，因此真实多轮问答仍未通过。合计保留 ¥0.0316512 预留，不能视为实际扣费。每轮状态、用量和截图以主工作区 `artifacts/branch-work/product-demo/` 的交接及证据索引为准；这些记录不判定正式指标或关口通过。

## 5. 查看四级预警

1. 任务完成时会自动生成预警；也可进入“预警中心”，选择一个运行后点击“按当前规则判级”。
2. 页面展示等级、规则版本、统计指标和引用。当前暂定计算为**最后一轮有效决策中模拟投诉意向数 / 有效决策数**：红 ≥40%，橙 ≥20%，黄 ≥5%，低于 5% 为蓝。
3. 这是模拟 Agent 的投诉意向比例，不是现实投诉率，不代表保险公司的全渠道投诉量；阈值未经真实事件校准。核对 `source_record_ids`、动作引用和是否发生截断。

## 6. 生成企业微信或邮件预览

在预警详情中选择“企业微信”或“邮件”，点击“生成通知预览”。返回/页面展示载荷，`delivery_status=dry_run`、收件人为空、`sent_at=null`、`network_requests=0`。预览明确写出 `OFFLINE PREVIEW ONLY`。

`dry_run` 只表示载荷生成和留档，不向企业微信或邮件发送，也不产生送达回执。预警的本机评估时间不是历史事件首次发现时间；预览耗时不是红色预警实际推送 SLA。不要把预览结果作为通知已发送的证明。

## 运行边界速查

| 标记 | 含义 | 可支持的结论 |
| --- | --- | --- |
| `real_historical` | 截止前合格的真实历史来源材料 | 证明输入材料的来源/时间范围；若执行模式为替身，不能证明真实模型推理或未来走势。 |
| `synthetic` | 虚构或合成材料 | 功能、流程和规则测试；不证明真实平台覆盖、真实投诉或真实事件预测。 |
| `offline_dynamic_substitute` | 本机动态执行器；根据 Agent 当前状态、独立记忆和运行时消息生成后续决策 | 本机工程闭环。`model_calls=0`、`network_requests=0` 是应用运行账本，不是 OS 抓包证据。 |
| `llm_grounded_report_qa` | 获准的云模型报告追问；范围绑定当前报告和截止前证据 | 有引用的多轮报告解释。它不把已有离线仿真变成真实模型仿真，也不证明走势预测或正式指标达标。 |
| `dry_run` | 通知载荷预览 | 证明预览已生成；不证明发送、送达或 30 分钟红警 SLA。 |
