# 文档入口

当前源码提交只保留运行和交付所需的简明文档：

- [新版命题](sources/2026-09-30-新版命题-多智能体仿真舆情监测.md)：当前需求与验收目标。
- [命题解题思路](solution-approach.md)：完整命题的解读、难点、方案、步骤、验证和风险备选。
- [初赛后改进计划](planning/初赛后改进计划-2026-10-11.md)：四分支当前起点、优先任务、交付和集成关口。
- [当前架构与设计依据](design/当前架构与设计依据-2026-10-11.md)：已实现链路、共享契约和下一步设计决策的证据门槛。
- [部署与运行](delivery/deployment.md)：本机和 Docker 启动方式。
- [API 参考](delivery/api.md)：接口与请求约束。
- [用户操作指南](delivery/user-guide.md)：案例、任务、报告与预警操作。
- [测试与运行报告](delivery/test-report.md)：已有验证、未通过关口与限制。

当前阶段的共享计划放 `docs/planning/`，当前设计依据放 `docs/design/`；两者使用“名称-YYYY-MM-DD.md”命名，日期为该版本的基线日。旧 Day 阶段规划已迁入本机 `docs/archive/planning/`，过程记录仍在 `docs/records/`，运行原始证据在 `artifacts/`；这三处均不随精简源码提交。上列当前计划与设计依据是源码协作文档；实际验收状态仍以测试与运行报告为准。
