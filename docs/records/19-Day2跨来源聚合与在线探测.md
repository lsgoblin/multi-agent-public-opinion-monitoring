## 两个公开来源的同一事件

[新增事件包](../../data/public/unh_change_20240222_day2_multisource_event.json)沿用 UnitedHealth Group / Change Healthcare 事件的 SEC 原始 8-K 和既定 cutoff `2024-02-22 16:48:39 EST`。新增的是 [Optum 官方事件状态页](https://status.changehealthcare.com/incidents/hqpjz25fn3n7)的一条截止前更新，`update_id=9j1b644m46kx`。其[公开 Statuspage API](https://solution-status.optum.com/api/v2/incidents/hqpjz25fn3n7.json)返回 `created_at=2024-02-21T16:27:23.594-05:00`、`updated_at=2024-02-21T16:40:49.526-05:00`、`display_at=2024-02-21T16:27:23.000-05:00`；所选正文 SHA-256 为 `a51e2fd56038c789527055b2fa2e6de133d864a17b318120a92791cef825aa81`，本次重新抓取与事件包字段一致。

这个 cutoff 是 **SEC 首个独立可见证据 +30 分钟**的原有观察点。Optum 事件页已有更早的公开见证，所以此包用于检验“SEC 披露被发现后，先前公开的状态通告能否一同检索”，不能解释成“整个网络事件首次公开后 +30 分钟”的快照，也不能以两源贯通改写 Day 1 的时间口径。

[同期帖子存档](https://arctic-shift.photon-reddit.com/api/posts/ids?ids=1awwr9j)记录 `retrieved_on=1708573941`，即 `2024-02-21 22:52:21 EST`，其标题及目标链接指向**同一事件页**。保守地以这一时刻作为状态页可见证据；它没有保存更新正文当时的完整字节。更新内容的截止前版本判断依据是官方 API 保留的更新 ID、创建及最后编辑时间和当前所见正文哈希，不能宣称存档独立证明了全部文字。摘要只覆盖该更新所述的网络中断、断开系统及当日持续预期。状态页现含大量截止后更新，适配器仅抽取指定更新，拒绝创建、编辑或展示时间晚于 cutoff 的版本；原始 API 整页不持久化、不入图。

SEC 原件是监管披露，Optum 状态页是公司事件状态通告：它们构成**同一事件的两个来源记录**，不是五目标平台的跨平台覆盖，也不等于全渠道去重。事件包仍保留 2024-03-08 后续材料作为 `evaluation_only`，不进入快照、采集或检索。新增来源仅供 Day 2 内部验证，不加入已授权的 DeepSeek 单条 SEC 外发范围。
